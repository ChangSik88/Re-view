# 해몽 태그 31개

작성일: 2026-11-04
상태: 검토 중

해몽 DB 구조 잡기 전에 먼저 정하는 태그 초안임. 키워드는 승인 받는 동안 추가될 수 있음.

## 이유

- 현재 키워드 파일은 대부분 전통 해몽에 나오는 소재 위주이고 현대적 요소가 부족함. 게임, SNS, 로또, 도박장, 애니메이션 같은 키워드가 없음.
- 결과 카드를 타로 형태로 제공할 건데, 카드가 너무 많으면 사용자가 수집 욕구를 느끼지 못할 가능성이 높다고 봄.
- 키워드마다 카드를 그리면 키워드가 늘어날수록 제작 비용도 같이 늘어남.

그래서 꿈 요소를 "무슨 역할을 하는지" 기준으로 태그를 붙이고, 카드는 태그 단위로 만드는 방향을 생각 중임. 휴대폰이든 편지든 역할이 같으면 같은 태그로 묶는 방식임. 처음 보는 요소도 태그만 맞으면 DB 해석을 쓸 수 있음.

## 태그 정리 과정

초안 30개를 Claude와 Kiro(GPT 5.6 Terra)가 서로의 결과를 보지 않고 키워드 300개에 각각 분류해 봄. 대표 태그는 208개(69.3%), 후보 태그까지 포함하면 240개(80.0%)가 일치함.

여기서 빈자리로 나온 후보 3개를 기존 태그와 겹치는지 다시 확인함.

| 후보 | 결과 | 이유 |
|---|---|---|
| 학습 | 추가 | 평가는 판단받는 압박, 학습은 배움이라 구분됨 |
| 통찰 | 보류 | 해당 키워드 대부분이 자기 모습, 길찾기, 해방, 동경으로 들어감 |
| 감정표출 | 제외 | 정화, 통제 상실과 겹치고, 감정 자체는 감정 라벨 9종이 따로 있음 |

## 원문 대조 결과

처음 적은 과거 예시 77개를 원문과 대조함.

| 결과 | 개수 | 예시 |
|---|---:|---|
| 소재와 뜻이 맞음 | 24 | 똥, 금, 태몽, 호랑이, 용 |
| 소재는 있는데 뜻이 다름 | 28 | 돼지, 거울, 이빨, 벌거벗음, 죽음 |
| 원문에 없음 | 25 | 까치, 여우, 노름, 과거 시험, 약초 |

- 뜻이 다른 건 원문 구절로 교체했고, 대체할 구절이 없는 태그 5개(의무, 위장, 요행, 자기 모습, 시간 압박)는 "원문에 없음"으로 적음. 이 태그들은 현대 해석 위주로 가야 함.
- 벌거벗음, 벼락, 칼에 베임은 원문에서 길몽임. 태그만으로 풀면 흉몽으로 나올 수 있어서 대상별 예외로 따로 저장해야 함.
- 돼지는 원문에서 재물이 아님(食豬肉主疾病至 등). 돼지꿈, 까치는 한국 쪽 해몽일 가능성이 있는데, 믿을 만한 한국 출처는 아직 확인 못 함.

## 자동 분류 체크

실제 서비스 모델(`gemini-3.1-flash-lite`)에 태그 31개를 주고, 같은 문제 44개를 3번씩 분류시켜 봄. 기본 설정으로 먼저 돌리고, 일관성이 부족해서 설정을 바꿔 다시 돌림.

| 항목 | 기본 설정 | 개선 설정 |
|---|---:|---:|
| 3번 모두 같은 태그 | 41/44 | 44/44 |
| 정답 | 115/123 | 117/123 |
| 목록에 없는 태그 | 2번 | 0번 |
| NONE | 15번 | 0번 |
| 모르는 고유명사 표시 (학정 등) | 9/9 | 9/9 |

- 개선 설정은 온도 0, 태그 목록 밖 답변 차단, NONE 제거임. 모르는 고유명사는 태그와 별도로 "물어봐야 함" 표시만 하게 함.
- 예시에 있는 요소 11개는 기본 설정에서도 33/33 정답임.
- 남은 오답은 이빨(끝맺음), 꿈속의 꿈(미지) 2개이고, 3번 다 같은 답이 나옴. 이런 소재는 DB에 먼저 등록해서 고정할 계획임.
- 기본 설정으로 키워드 300개도 분류해 봤는데, Claude와 Kiro가 합의한 208개 중 174개가 일치함. 개선 설정으로는 아직 안 돌림.

## 한계

- 테스트 문제와 정답은 Claude가 실행 전에 만든 것이고, 장면이 깔끔한 편임. 실제 사용자 꿈에서는 정답률이 더 낮을 수 있음.
- 꿈 글에서 요소를 뽑는 단계는 테스트하지 않음.
- 같은 요소를 다른 말로 썼을 때 같은 태그가 나오는지는 아직 테스트하지 않음.
- 태그 정의와 예시 일부는 사람 검토가 아직 안 됨.
