# 디자인 토큰 (FE 실제 구현 기준)

`FE/lib/`의 실제 코드에서 추출한 값입니다. 와이어프레임이 아니라 **지금 앱에 적용된 상태**입니다. 피그마의 Variables / Text styles에 그대로 옮겨 찍으세요.

> Flutter는 색을 `0xAARRGGBB`(앞 2자리가 투명도)로 씁니다. 아래 표에 피그마용 `#RRGGBB`와 불투명도(%)로 변환해 두었습니다.

## ⚠️ 옮기면서 정리하면 좋을 점

추출하면서 눈에 띈 **실제 구현의 비일관성**입니다. 피그마로 옮기는 김에 정리하면 좋습니다.

1. **다크/라이트 혼재**: 로그인·채팅·꿈 리스트·상세는 다크(`#100D10` 배경), 홈·스토어 일부는 라이트 톤(`#ECEEF2`, `#030213`)이 섞여 있습니다. 와이어프레임과 실제가 달라 보이는 주원인일 수 있습니다.
2. **거의 같은 색 중복**: `#1F1B21` vs `#1F1C21`처럼 미세하게 다른 값들이 있습니다. 토큰으로 합치세요.
3. **반쯤 정수 라운드**: `6.75`, `12.75` 같은 값은 특정 디자인 툴(shadcn) 기본값이 그대로 넘어온 흔적입니다. `6`/`12`로 라운딩할지 결정하세요.
