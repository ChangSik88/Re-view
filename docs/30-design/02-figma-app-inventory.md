## 이 문서를 먼저 읽어야 하는 이유

**레이어명을 믿으면 안 된다.** 전수 조사에서 확인된 어긋남:

- `AI Chat Home` 4개는 중복 시안이 아니라 `{모닝루틴=꿈 / 나이트루틴=하루} × {통계 뷰 / 목록 뷰}` 조합이다.
- `채팅 홈`(`554:680`)은 채팅 홈이 아니라 **하루 상세의 AI 감정 인사이트 탭**이다.
- `캘린더> 전체보기 클릭`(`516:477`)은 캘린더가 아니라 **내 꿈나라 대시보드**다.
- `ic:round-refresh` 2개(`542:302`, `542:381`)는 아이콘이 아니라 **등장인물 수정 다이얼로그**의 두 상태다.
- `Frame 1 / 11 / 12 / 13`은 화면이 아니라 캔버스 왼쪽의 **노란 밴드 라벨**(홈화면 / 로그인·회원가입 / 채팅 화면 / 스토어 화면)이다.
- `홈>스토어 전체보기 클릭`(`509:560`)과 `스토어>다이어리(x)`(`503:2068`)는 **픽셀 단위로 같은 화면**이다.

## Figma에 아직 없는 화면

디자인 작업이 필요한 화면이다. 구현은 디자인 이후로 미룬다.

| 화면 | 근거 |
|---|---|
| 꿈 상세 · `AI 감정 인사이트` 탭 | 하루 상세(`554:680`)에만 있고 꿈 쪽은 탭만 있고 화면이 없다 |
| 설정 | 하단탭 4번째. 현재 FE는 "준비 중" 스낵바 |
| 감정 전체보기 | 링 3개 밖의 감정을 보는 화면. [ADR 0002](../40-decisions/0002-emotion-label-taxonomy.md) 참고 (2026-09-20 결정) |
| 검색 결과 | 대시보드 상단 돋보기의 도착지 |
| 알림 목록 | 대시보드 상단 벨의 도착지 |

## 신규 기능 목록

기존 코드에 대응이 없는 것들이다. BE 지원 여부는 별도 확인이 필요하다.

1. **Dream Calendar** — 홈 주간 위젯 + 월간 전체보기 화면. 날짜별 감정 이모지.
2. **하루(나이트루틴) 전용 IA** — 내 일기장 대시보드, 하루 상세.
3. **AI 감정 인사이트** — 어제 꿈 → 오늘 감정 전이, 감정 변화 라인차트(4일치), 추천 카드.
4. **감정 통계 3종 원형** — 행복/불안/편안 비율. 기존 `report_service`가 이 형식을 주는지 확인 필요.
5. **채팅 중 구조화 정보 카드** — 장소/등장인물/감정/상황/기타 메모 추출 및 항목별 수정 다이얼로그.
6. **장바구니** — BE에 cart 도메인 없음.
7. **Google 소셜 로그인** — BE `user` 도메인에 소셜 인증 없음.
8. **검색 / 알림** — 대시보드 상단 아이콘. 대응 화면이 캔버스에 없음.
9. **상품 이미지 캐러셀 + 뱃지(인기상품/신상품)** — `store` 스키마에 이미지 다중·뱃지 필드 있는지 확인 필요.
