# 약관·동의문

2026-11-16 작성 · 버전 0.1 초안

## 가입 화면 항목

- [필수] 만 14세 이상입니다.
- [필수] 서비스 이용약관에 동의합니다.
- [필수] 개인정보 수집·이용에 동의합니다.
- [선택] AI 모델 개발·학습·평가 및 성향 분석 연구를 위한 개인정보 이용에 동의합니다.
- [선택] 마케팅 목적의 개인정보 이용에 동의합니다. 실제 채널 확정 후 활성화한다.
- [선택] 광고성 정보 수신에 동의합니다. 실제 운영 채널별로 구분한다.

각 항목에서 전문을 열 수 있게 하고 선택 동의는 기본 미선택으로 둔다. 개인정보 처리방침 링크를 제공한다. 외부 제공 동의는 제공처·목적·항목·기간 확정 후 실제 제공 전에 별도로 받는다. 단순 연령 확인 체크박스의 충분성은 확인 방식에 맞춰 검토한다.

## 공개 전에 확정할 정보

- 운영자명, 문의 이메일, 개인정보 보호책임자, 시행일
- 계정 복구 화면 경로, 30일 경계 처리 및 삭제 실행 보장. 본인 확인은 기존 아이디·비밀번호를 사용하는 것으로 확정
- 연구용 사본의 지체 없는 삭제를 보장할 실행 방식과 진행 중인 학습의 중단·제외 방식. 연구 보유 기간은 최초 수집·생성일부터 최대 5년이며, 철회·탈퇴 신청 후 저장·이용 중단 및 연구용 사본 삭제, 완료된 학습의 영향 제거 한계 고지로 확정
- 민감정보 처리 여부와 별도 동의, 대화에 포함된 제3자 개인정보 처리 방법
- 실제 AI·호스팅·저장소 업체, 재위탁, 처리 국가, 보관 기간, 업체 자체 학습 여부
- 마케팅 채널, 수집 항목, 보유 기간과 발송업체
- 판매 상품, 결제·환불 수단, PG/앱마켓, 정기결제 여부
- 외부 제공처와 구체적인 제공 조건
- 이름·닉네임 선택, 실제 수집 로그와 음성 처리 정보

## 현재 구현과의 차이

백엔드에 가입 입력 변경, 동의 이력·복구 API, 연구용 사본의 저장 통제·철회 시 삭제와 만료 정리, 기록 분리 보존을 구현했다. 연령은 자기 확인값을 서버에서 검증한다. 프론트 연동, 실제 학습 파이프라인과 마케팅 발송·채널별 수신 관리, 비공개 이미지 접근은 남아 있다. 기존 회원의 생년월일·성별 데이터는 별도 삭제 정책 결정이 필요하다.

기존 통합 초안은 저장소 밖 `outputs/Re-view_약관_동의문_초안.md`에 남아 있다. 앱·웹 연결 시에는 이 폴더의 분리 문서를 기준으로 검토한다.
